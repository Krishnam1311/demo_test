# Demo Test

This is a demonstration repository used for testing automated ticket dispatching, agent worktree management, and workflow verification.

## Getting Started

Follow these steps to get started with the repository:

### 1. Prerequisites

Ensure you have Git installed on your system.

### 2. Clone the Repository

```bash
git clone https://github.com/Krishnam1311/demo_test.git
cd demo_test
```

### 3. Verification & Code Style

To verify changes and ensure clean whitespace and formatting across the repository, run:

```bash
git diff --check
```
